\section{Testing and Performance Evaluation}
\label{sec:testing}

\guide{
Twenty marks. The 1st+ rubric wants ``extensive quantitative testing
with benchmarking and deep critical analysis'' --- so concrete numbers
beat narrative every time. Four sub-sections, each one ending in a
specific numerical artefact:
\begin{enumerate}
  \item Functional verification (sequence test, pass criteria).
  \item Closed-loop accuracy and repeatability (ISO-9283-style;
        $N=30$ trials with a fiducial; with and without payload).
  \item End-to-end latency (GPIO debug-pulse pair on a shared scope;
        histogram across $N=200$ frames).
  \item Power and link robustness (current draw by mode; checksum
        failure rate vs distance up to 10\,m).
\end{enumerate}
Finish with a results table summarising every metric, and a short
discussion of what the data revealed (e.g.\ ``adding the bulk cap
reduced reset events from X/min to 0''). The before/after
optimisation evidence is the single biggest lever for marks above
60\,\% in this rubric row.
}
